# Supported formats

The machine-readable registry at `services/api/conversion_registry.json` is generated by running real conversions and decoding every output. The API disables the registry unless Pillow and FFmpeg versions match the tested versions.

| Input | Output | Notes |
|---|---|---|
| PNG, JPEG, WebP, AVIF, GIF, TIFF, BMP | PNG, JPEG, WebP, AVIF, GIF, TIFF, BMP | 49 verified pairs on the recorded Pillow version. Animated inputs are rejected. GIF fixture output is static. |

| WAV, MP3 | MP3, WAV, FLAC, AAC, M4A, OGG, Opus | 14 verified pairs. Lossy outputs use 192 kb/s. |
| MP4, WebM | MP4, WebM, MOV, MKV, and the listed audio outputs | 22 verified video and audio extraction pairs. H.264/AAC is used for MP4/MOV/MKV and VP9/Opus for WebM. |

Output files are reopened/probed and validated. Metadata is not preserved. Images default to 20 MiB; media inputs default to 100 MiB and outputs to 200 MiB. Configure with `MAX_IMAGE_UPLOAD_BYTES`, `MAX_UPLOAD_BYTES`, and `MAX_MEDIA_OUTPUT_BYTES`.

Documents, archives, spreadsheets, and media input containers other than MP4/WebM are not enabled. Platform URL analysis/download is enabled when yt-dlp and ffprobe are installed and requires outbound network access. It is not a verified platform compatibility promise: each submitted URL is analyzed at runtime, and actual external platform integrations have not yet passed a test in this environment.
